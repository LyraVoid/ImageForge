# apatch

Status: **not bundled**.

ImageForge v0.1 does not ship any code, binary or artifact from apatch. This
directory exists so that the integration can be reviewed properly when it happens.

Before any apatch code or artifact is added:

1. read the current upstream repository revision, its build system and its LICENSE;
2. copy the upstream LICENSE file into this directory verbatim;
3. record the repository URL, the pinned revision and the retrieval date below;
4. list every local modification made to the upstream source.
